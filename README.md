# Tamara · Administración

Página de administración de Tamara (prototipo académico, Grupo 1, Hackatón USM, Facultad de Derecho).

- Solo entran cuentas de administrador. Las demás personas usan la página del tribunal: https://gaacb2003-alt.github.io/tamara/
- Desde aquí se manejan cuentas, perfiles y permisos, se editan las causas y la portada y los avisos de la página del tribunal.
- La seguridad la hace cumplir la base de datos (Supabase, reglas por fila); esta página solo contiene la clave pública del proyecto.

Casos y datos ficticios.
